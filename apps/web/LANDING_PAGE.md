# 红中排版 - 落地页功能说明

## 概览

已为红中排版添加了专业的落地页，用户首次访问时将看到产品介绍页面，登录后可进入编辑器。

## 路由结构

- **`/`** - 落地页（LandingPage）
- **`/editor`** - 编辑器页面（原App组件）
- **`/*`** - 其他路径重定向到首页

## 落地页功能

### 1. 导航栏

- 固定在页面顶部
- Logo + 品牌名称
- 登录/注册按钮（未登录时）
- 用户菜单（已登录时）

### 2. Hero 区域

- 大标题："红中排版 篇篇爆红"
- 产品简介
- "开始创作" CTA按钮
- 红色渐变背景 (#E60012 → #C00010)

### 3. 特性展示区域

三个特性卡片：

1. **云端存储 随时随地**
   - 图标：Cloud
   - 描述：文章安全存储在云端服务器，无论何时何地都能访问

2. **支持上传图片**
   - 图标：ImageIcon
   - 描述：集成多家图床服务，一键上传图片，自动生成外链

3. **不仅是排版，还封装了运营技能**
   - 图标：TrendingUp
   - 描述：内置精美主题模板，支持代码高亮、数学公式、流程图等

### 4. CTA 区域

- 标题："准备好创作爆款文章了吗？"
- "免费开始" 按钮

### 5. Footer

- 版权信息

## 交互逻辑

1. **点击"开始创作"按钮**：
   - 跳转到 `/editor` 编辑器页面
   - 如果未登录，用户可以在编辑器中再登录（会提示需要登录才能使用云端存储）

2. **点击导航栏"登录/注册"按钮**：
   - 弹出 AuthModal 登录注册弹窗
   - 登录成功后，导航栏显示用户菜单

3. **点击编辑器Logo**：
   - 返回首页落地页

## 样式特点

- **响应式设计**：完美适配移动端和桌面端
- **渐变背景**：Hero区域使用品牌红色渐变
- **动画效果**：
  - fadeInUp 入场动画
  - 按钮悬停效果
  - 卡片悬停抬升效果
- **毛玻璃效果**：导航栏使用 backdrop-filter blur

## 技术实现

- **React Router** (v7.13.0)：客户端路由
- **Lazy Loading**：AuthModal 和 UserMenu 懒加载
- **Zustand**：认证状态管理
- **Lucide React**：图标库

## 部署注意事项

由于使用了客户端路由，需要配置服务器将所有路径重定向到 index.html：

### Nginx 配置示例

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

### Vite Preview

```bash
pnpm preview
```

会自动处理客户端路由。

## 开发命令

```bash
# 启动开发服务器
pnpm dev:web

# 访问落地页
http://localhost:5173/

# 访问编辑器
http://localhost:5173/editor
```
